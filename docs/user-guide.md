# ScrollFerry · 舷渡 使用说明

适用版本：v2.1.3。软件名称为“舷渡 ScrollFerry”。

典型流程：打开 PDF → 校对拆题结果 → 导出截图 → 上传整卷素材 → 倒序录题。

## 1. 使用前准备

准备能够正常显示的 PDF，以及有素材库和题库操作权限的小鹅通账号。建议先在 PDF 阅读器中检查页数、公式和图片是否完整，优先使用带文字层的单栏试卷。

软件不提供 Word 转 PDF。Word 文件请先在原软件中导出 PDF 并检查完整性。纯扫描件尚无 OCR 支持，可能提示未识别到题目，不能保证直接打开后进入手动校对。

### 安装启动

| 方式 | 操作 |
| --- | --- |
| Windows 安装版 | 运行 `ScrollFerry-Setup-2.1.3-x64.exe`，选择安装位置和快捷方式；无需另装 Python |
| Windows 源码版 | 安装带 Tcl/Tk 和 Python Launcher 的 Python 3.11+，双击 `start_windows.bat` |
| macOS 源码版 | 准备带 Tcl/Tk 的 Python 3.11+，双击 `start_mac.command` |

安装版默认安装在当前用户目录。安装向导为英文，应用界面为中文。源码启动脚本会使用或建立 Python 环境；上传前还需运行对应系统的“安装上传组件”脚本。

电脑需要 Chrome 或 Edge 中至少一个。Windows 默认浏览器为两者之一时优先使用它，否则先 Chrome 后 Edge；macOS 当前也是先 Chrome 后 Edge。上传使用软件专用窗口，日常浏览器已登录不代表这个窗口也已登录。

## 2. 打开与检查试卷

从“导入文件”选择“打开 PDF”，选择试卷并等待居中进度窗口完成分析。此时不需要选择导出目录。

如果题目与答案解析分成两份文件，点击“题目＋解析 PDF”，先选择题目卷，再选择解析卷。软件按题型分区和题号匹配，支持各题型重新编号、文字参考答案；同一分区内的重复题号仍提示核对。集中答案表暂不支持。

“45～46题基于以下题干”这样的共用材料会复制到每道相关题的题干。论证有效性分析和论说文本地按解答题处理、上传为问答题，使用原卷参考思路或解析原图作为参考答案。点击解析截图会切换到解析卷；翻页也可在两卷间连续浏览。分卷工程需要同时保留两份源 PDF。

分析完成后，左侧列出题目和截图，右侧显示试卷。先核对总题数及题型，再检查各题：

- 题干是否完整，有没有混入其他题目或页眉页脚。
- 选项是否齐全、顺序正确；五选项题应有 A–E。
- 选择题答案字母是否与原卷一致。
- 答案、解析是否对应本题，跨页内容是否完整。
- 原题号和选项标号是否去除，公式、上下标及图表是否被误遮盖。

`⚠` 表示有待检查问题，`✓` 表示已勾选校对；没有警告也不等于无需预览。鼠标滚轮在所在区域轻缓滚动：题目列表、整个左侧面板、PDF 页面和截图预览分别独立响应。PDF 支持滚轮连续跨页，也可使用“上一页”“下一页”；Shift＋滚轮可横向移动 PDF。点击左侧截图项后会切换到对应页并自动显示截图框，长截图定位到顶部，跨页内容显示原 PDF 上一页尾部与下一页头部，并分别显示选框。

## 3. 调整截图

先在左侧选中具体截图，再选择操作模式。

| 模式 | 操作与用途 |
| --- | --- |
| 浏览 | 滚动、翻页检查原卷 |
| 调整截图 | 拖动矩形，设置或调整当前截图范围 |
| 擦除标号 | 在编号上拖动矩形，以白色覆盖目标文字 |
| 添加片段 | 框选补充内容，将跨页区域追加到同一张导出图片 |

添加片段按添加顺序纵向拼接，应先框上半部分，再翻页补下半部分。同页有多个片段时，“调整截图”修改该页最后一个片段。

涂白区域应覆盖全部编号，但尽量远离正文和公式。“解析”两个字保留即可，导出时会给截图增加白色留边。

操作失误可用“撤销”“重做”。Windows 快捷键为 Ctrl+Z、Ctrl+Shift+Z；macOS 为 Command+Z、Command+Shift+Z。Esc 取消当前拖动并返回浏览。撤销记录只在当前会话内保留，不能代替保存工程。

漏掉截图时，选中题目，在“新截图类型”中选择类型，点击“新增截图”并框选。遗漏整题时使用“新增题目”，补齐截图后设置题型和答案。

## 4. 答案、校对状态与工程

修改左侧题型或答案后，点击“保存本题校对”。单选填一个大写字母，如 `E`；多选用连续大写字母，如 `AC`。

填空题在本地仍保留“填空题”，上传会自动变成问答题，优先使用“答案原图”，不必强行将复杂公式转成文字。

当前“此题截图和答案已校对”勾选逻辑仍要求填空题有文字答案。只有答案截图时可以不勾选；上传会接受有效答案原图，并忽略“公式答案已保留截图，文字识别需复核”这一项提示。其他警告仍应核对，不要为了清除警告随意填写答案。

“保存工程”保存题型、答案、框选和涂白坐标。“读取工程”可继续校对。工程引用原 PDF 路径，不包含 PDF 本身，请保留源文件并尽量不要移动它。

## 5. 导出截图

点击“导出截图”后选择保存位置。所选位置可以已有文件，软件会在其中新建带时间和随机编号的批次子文件夹。当前会话再次导出时默认使用上次位置。

示例图片名：

```text
六月数学_a1b2c3d4_Q0001_02_option_A.png
```

名称包含试卷名前缀、批次编号、题号、图片序号和类型。上传中的图片不要手动改名。

| 文件 | 作用 |
| --- | --- |
| PNG 图片 | 题干、选项、答案原图和解析 |
| `batch.json` | 试卷名、前缀、素材分组 |
| `manifest.json` | 题目与图片对应清单，用于上传和恢复 |
| `project.json` | 导出时的工程快照 |
| `warnings.json` | 识别提示 |
| `status.json` | 导出完成状态 |

导出不要求全部题目勾选“已校对”，但每张截图必须有有效区域。导出取消或失败后，该批次不能上传；重新导出会建立新批次。

## 6. 上传小鹅通

检测、拆题、导出和上传的进度窗口会显示当前步骤、当前阶段计数、已用时间、步骤耗时和最近操作记录。上传会显示素材检查数量、每批上传数量、已确认图片数及题目保存状态；后台尚未返回结果时显示等待状态，不估算百分比。小船与波纹动画表示界面仍在响应，不代表后台一定已完成。点击取消后会等待当前操作返回，已完成的上传进度仍保留。

点击“上传到小鹅通”，或在导出完成窗口直接点击同名按钮。当前会话已导出时使用该批次；重启后选择原批次的 `manifest.json`。上传面板显示可上传、已保存和待补全题目数量，并自动绑定同名题库分类。

选择本次上传范围，再点击“开始上传”。失败窗口可点击“重试”，已保存进度会保留。

| 选项 | 实际行为 |
| --- | --- |
| 仅上传图片素材 | 建立或复用素材分组，上传全部图片，不创建题目 |
| 先试传一道题目 | 先上传整卷素材，再真实保存倒序中的下一道可用题目 |
| 继续上传全部待处理题目 | 完成素材上传后，倒序保存全部通过校验的题目 |
| 查看待补全题目 | 查看暂时无法录入的题目及原因 |

首次建议先试传一题。软件会自动：

1. 打开专用浏览器，等待登录小鹅通。
2. 在素材中心新建或复用“试卷名_批次编号”分组，集中上传图片，每批最多 100 张。
3. 建立或复用同名题库分类。
4. 从清单最后一题开始，按完整图片名搜索并插入题干、选项、答案及解析。
5. 设置正确选项并保存，确认返回题库列表后记录成功。

填空题和解答题均按问答题上传。选择题按截图数量调整选项框，五选项题会自动新增第五项。倒序依据导出清单顺序，历史已保存题目不会重排。

上传期间保持软件和专用浏览器窗口打开，避免手动操作其中的表单。进度条反映当前处理阶段，不是精确剩余时间。取消后需等待当前步骤结束，已保存到后台的内容不会撤回。

## 7. 恢复与数据保留

| 系统 | 登录资料、上传进度及诊断文件 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\ScrollFerry` |
| macOS | `~/Library/Application Support/ScrollFerry` |

上传记录位于 `batches` 子目录，浏览器资料位于 `browser-profiles`。PDF、工程和导出截图仍在用户指定的位置。

恢复时选择原 `manifest.json`，软件跳过已保存题目。请同时保留原批次路径和本机用户数据；移动批次、换电脑或删除进度可能失去断点记录。

保存超时不一定代表保存失败。提示“上次已点击保存但未确认结果”时，先到后台核对；当前没有人工核销回执的操作界面，不要删除进度或重新导出后强行重传，以免重复录题。

上传后如需改图或改答案，先核对已保存情况，再从工程重新导出。新批次会有新分组，不会自动替换旧题。

## 8. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 未识别到题目 | 检查是否为扫描件或不支持的版式；当前没有通用 OCR |
| 公式或跨页内容不完整 | 调整截图、添加片段并预览，也检查源 PDF 是否正常 |
| 某题没有录入 | 查看待补全列表，检查题干、连续选项、答案及其他警告 |
| 公式答案只有图片 | 保留答案原图，按问答题上传；其他问题仍需核对 |
| 浏览器无法启动 | 安装 Chrome 或 Edge，或关闭此前的软件上传窗口后重试 |
| 找不到素材 | 检查完整文件名、目标分组、素材是否被改名或删除 |
| 清单或图片副本已变化 | 先核对后台，再导出需要修改的内容，不覆盖旧回执 |
| macOS 提示 Operation not permitted | 检查终端对项目文件夹的访问权限，查看 `tmp/mac-launch.log` |
| 后台页面操作超时 | 保留错误提示及用户数据目录中的 `upload-error.png/json`，供维护者排查 |

完成后在小鹅通抽查题目数量、分类、正确选项、公式显示和解析对应关系。
