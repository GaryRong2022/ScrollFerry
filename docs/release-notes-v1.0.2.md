# ScrollFerry · 舷渡 v1.0.2

ScrollFerry 将 PDF 试卷拆分为题干、选项、答案和解析截图，再批量录入小鹅通题库，保留数学公式、图表及原有排版。

## 功能与调整

- 自动识别带文字层 PDF，支持截图范围调整、编号涂白、跨页拼接、撤销和重做。
- 填空题统一按问答题上传，优先使用答案原图，保留公式。
- 按导出清单倒序添加题目，支持五选项题及动态增加选项框。
- 图片名称包含试卷名前缀和批次编号，每次导出建立独立文件夹。
- 先集中上传整卷素材，再创建或复用同名题库分类，按完整图片名搜索并插入。
- 支持试传一题、上传全部可用题目及断点恢复；不确定的保存结果暂停核对。
- 更新软件 Logo，统一窗口名称为 `ScrollFerry·舷渡-小鹅通题库上传工具-v1.0.2`。
- 登录资料和上传进度存放于用户数据目录，支持 Chrome / Edge 启动回退。
- 增加 Windows 安装包构建配置、使用说明及技术说明。

## 安装与使用

Windows 安装包包含 Python 和运行依赖，电脑仍需安装 Chrome 或 Edge。安装包以成功的 Actions 构建产物为准。

打开 PDF → 校对截图和答案 → 导出批次 → 试传检查 → 上传全部可用题目。

试传会先上传整卷素材，并真实保存一道题目。首次使用时需在软件专用浏览器窗口登录小鹅通。

## 已知限制

- 暂无纯扫描件 OCR 和 Word 转 PDF 功能；复杂版式可能需要手动校对。
- 小鹅通后台改版可能影响上传，历史已保存题目不会自动修改或重排。
- 恢复上传需保留原导出目录路径和本机上传记录。
