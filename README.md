# ScrollFerry 试卷拆题助手

支持 macOS 和 Windows 的本地桌面初版，两者共用同一套 Python 代码。原始 PDF 不会被改写。

工具用于把含公式的试卷转换成题干、选项和解析图片，供小鹅通题库插入。公式从页面直接截图，不转写成普通文本；正确答案仍单独保存为文字。

## 运行

macOS：双击 `start_mac.command`。这台开发用 Mac 会自动使用已有 Python 运行环境，无需重新安装。其他 Mac 需安装带 Tcl/Tk 的 Python 3.11 或更新版本，启动脚本会创建本地环境并安装依赖。

如果提示 `Operation not permitted`，这是 macOS 文件夹访问权限错误，不代表未安装 Python。此项目位于“文稿”文件夹：在“系统设置 → 隐私与安全性 → 文件与文件夹”检查“终端”的“文稿文件夹”权限，允许后完全退出终端再启动。无需开启完全磁盘访问权限。诊断日志在 `tmp/mac-launch.log`。

Windows 源码运行：安装 Python 3.11 或更新版本（包含 Tcl/Tk 和 Python Launcher），双击 `start_windows.bat`。首次启动会联网安装依赖。安装 EXE 的 GitHub Actions 构建步骤见 [Windows 打包说明](docs/windows-packaging.md)，安装版不需要用户安装 Python。

其他系统可运行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m scrollferry.app
```

## 操作流程

1. 点击“打开 PDF”选择试卷。此时只自动分析，不选保存位置、不导出图片。
2. 在左侧选择题目/截图；默认“浏览”，鼠标滚轮上下滚动试卷，在页边缘继续滚动可翻页。
3. 需要修改时切换“调整截图”“擦除标号”或“添加片段”，拖动操作。Esc 取消当前框选并返回浏览。撤销/重做支持裁剪、涂白、片段追加、截图增删和已保存的答案修改；Mac 快捷键为 Command+Z、Command+Shift+Z。
4. “解析”字样保留，自动遮盖仅针对编号等标记。截图周围添加白色留边。
5. 点击“导出截图”时再选择保存位置。该位置可以已有文件；每次自动新建带时间和随机编号的批次文件夹，不覆盖旧批次。再次导出默认定位上次保存位置。每张截图从导出起采用“试卷名_批次编号_题号_序号_类型.png”，上传后保持同名。
6. 导出清单包含 `manifest.json`、`warnings.json`、`project.json`、`status.json`。处理和导出有居中进度弹窗，可取消；截图预览也在软件内居中打开。
7. “小鹅通上传”打开上传面板，可试传下一题或上传全部可用题目。首次在独立 Chrome / Edge 中登录；上传组件按编号搜索素材、插入并保存，带进度和断点记录。已实际完成示例试卷 22 题录入，详情见集成记录。

Word 转 PDF 功能已移除。请使用原软件导出且确认完整的 PDF。

## 当前能力与边界

- 混合题型试卷会按大题标题区分单选、多选、填空、解答题。填空题另存答案原图；解答题允许答案包含在完整解析中，不要求四个选项或一个答案字母。界面可更正题型。
- 对本次六月数学样本已验证：14 页、22 题（10 单选、6 填空、6 解答）、90 张图片。修复了题号与正文错行、跨页题干与解析、分段函数选项和高矩阵越过题号基线造成的错切。结果在 `output/六月数学_重新拆分`。
- 有大题标题且逐题带答案/解析的单栏版式，采用坐标标记、页面空白和嵌入公式矩形辅助确定边界。其他版式继续使用原有规则；该样本通过不代表任意排版均通过。
- 部分公式位于 PDF 内嵌图片中，无法靠文字层识别。保留 `answer` 图片并用 `answer_status` 标记，不将空答案伪装成已识别；原 PDF 图片里已有的异常字符也会保留。
- 自动处理带文字层、单栏题目；支持分行选项、同行标号选项，以及带“参考答案/答案与解析”等标题的独立答案区（按原题号匹配）。
- 识别 `1.`、`1、` 等题号，`A.` 等选项，`【答案】 A` 或 `答案：A`，以及 `【解析】` 等解析起始标记。
- 保留原页面截图里的公式和图片；用坐标遮盖标号。自动遮盖依赖文字定位，必须预览校对。
- 双栏、表格形式的集中答案、页眉页脚及复杂解析内部编号仍需适配。规则识别不能保证任意试卷的完整性和准确性；公式截图保留 PDF 像素，不重新排版。
- 扫描件尚未接入 OCR，可手动新增题目、框选截图、涂白标号并录入答案。
- 小鹅通单选题已完成真实试传：6 张图片批量上传、完整文件名搜索、题干/四选项/解析插入、正确答案 C 和保存。填空、问答编辑页已检查，尚未完成实际保存验证；平台页面发生变化时会停止并显示错误。选择题当前仅适配默认四选项；填空题目前一次填写一个空，复杂公式答案仍需校对。
- macOS 已验证窗口启动；Windows 启动脚本已提供，但尚未在 Windows 实机测试。尚未打包 APP/EXE。

## 小鹅通上传（试用）

源码运行先双击本系统的“安装上传组件”脚本，电脑需安装 Chrome 或 Edge 中至少一个；安装版已包含上传组件。Windows 优先尝试兼容的系统默认浏览器，失败后尝试另一个。登录资料存入用户数据目录的 `browser-profiles`，Chrome / Edge 各用独立目录，首次需要登录，不接管日常浏览器资料。Windows 用户数据目录为 `%LOCALAPPDATA%\ScrollFerry`，macOS 为 `~/Library/Application Support/ScrollFerry`。这些目录含登录信息，不应分享。

导出后点击“小鹅通上传”。程序先进入独立素材中心，以“试卷名_批次编号”新建专用分组，把整份试卷的所有图片集中上传到该分组（每批最多 100 张），然后自动创建或复用同名题库分类。每道题自动选择该分类，再按完整文件名搜索截图、插入并保存。分类无需手动填写。

v1.0.2：录题按试卷顺序倒序执行，已保存题目续传时跳过。填空题在小鹅通中统一创建为问答题，优先插入原答案截图；本地仍保留原题型。选择题支持 A–H 连续选项，五选项题会切出 E 并自动新增第五个选项框，同一行的多个选项分别切图。软件标题为“ScrollFerry·舷渡-小鹅通题库上传工具-v1.0.2”。历史已保存题目不会自动删除重建或调整顺序。

“仅上传整卷图片”只完成分组和素材上传，不创建题目；“试传下一题”也会先集中上传整卷图片，再仅录入下一道可用题目。待补全答案的题目照常上传截图，补全答案前不自动创建该题。相同批次恢复时复用分组及素材回执；已保存题目自动跳过。

`batch.json` 记录本批次的试卷名、文件名前缀与素材分组。试卷名中的 Windows 非法字符会替换，长名称截短为 30 个字符，分组名不超过平台 45 字限制。旧版已上传批次保留原有进度与图片名称，不自动迁移或改名；新版分组流程需重新导出，已录入题目不要重复保存。

答案缺失、公式答案未识别或截图有待核对问题的题目会列为待补全。修改答案后重新导出批次。重启软件也可点击“小鹅通上传”选择旧批次的 `manifest.json` 恢复，不需要再次导出。完整解答可作为问答题必填答案，并保留解析图片。

用户数据目录 `batches` 下的 `upload-queue.json` 区分图片与题目的状态；上传副本和错误诊断也存入该目录。旧批次进度首次读取时迁移并保留回执，不改写原导出文件。保存超时会暂停，不自动重复点击保存；需要在后台核对不确定结果。当前尚无人工核销不确定状态的界面，因此遇到该情况请保留批次用于排查，不要直接换批次重传。

接口依据：[Playwright 输入与文件上传](https://playwright.dev/python/docs/input)、[独立持久浏览器](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context)。平台控件来自已登录后台实际观察。

## 验证

测试额外依赖 `reportlab`，执行 `python -m unittest discover -s tests -v`。覆盖中文样本拆题、答案对应、标号涂白、无需人工勾选自动导出、编号图片导出和防覆盖；另覆盖上传队列恢复、文件改动检测、答案校验以及保存超时不重复提交；模拟执行器测试不代表小鹅通真实后台验收。

实际试卷回归测试：设置 `SCROLLFERRY_TEST_PDF` 为此次六月数学 PDF 的本地路径后执行上述测试，检查三种题型数量、单选答案、跨页解析和第 9 题四个完整分段函数。试卷文件不放入代码仓库。
